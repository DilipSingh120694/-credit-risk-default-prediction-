# Notebooks

`metrics-evidence-audit.ipynb` is an executed supplementary notebook. It calculates evaluation metrics from the counts in the report's two confusion-matrix figures. It is not the original model training notebook.

To add the original work:
1. Open [the Colab link from the report](https://colab.research.google.com/drive/1gddFnsGvNPTPWUdctya3i0DZbExL7nj0?usp=sharing).
2. In Colab select File > Download > Download .ipynb (or the equivalent notebook download option).
3. Save it as `credit-risk-original-analysis.ipynb` and add it here.
4. Check for private information, local credentials and inaccessible file paths before sharing.
5. Run its cells in a fresh environment with the source dataset; record package versions and settings.
6. Reconcile the technical-review issues and link the exported notebook from the main README.

If an exported notebook has different results, explain the run differences instead of silently replacing the original figures.
